Comet Courier is a canvas arcade game about a starlight delivery run: steer a courier ship with the mouse or keyboard, gather fallen star shards, and fly them home through the gate whose shape matches their light. Chain quick deliveries for combos, dash through void wisps to burst them, and grab shields, slow-time and magnet power-ups while the waves grow. Score 400 points to complete the route — or lose all three hulls to the void. Original art drawn in code, synthesized WebAudio sound, no build step, no network requests: static files under game/ that any static server can host.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
